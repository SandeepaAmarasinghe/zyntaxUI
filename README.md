# zyntaxUI / MonoUI
A Minimal Black & White Bootstrap Theme

**Clean. Sharp. Minimal. | A Brutalist Bootstrap 5 Theme**

---

## 🖤 Overview

**zyntaxUI** (also known as MonoUI) is a stark, high-contrast, and brutally minimal CSS theme that overrides Bootstrap 5 defaults. Designed for developers and designers who want a clean, distraction-free, and bold black-and-white aesthetic out of the box.

Created by Pasan Sandeepa at **[zyntax-studio](https://zyntax-studio.vercel.app/)**.

*   **GitHub Repository:** [SandeepaAmarasinghe/zyntaxUI](https://github.com/SandeepaAmarasinghe/zyntaxUI)
*   **Live CSS Link:** [zyntaxUI CSS](https://zyntaxui.pages.dev/zyntaxUI.css)

## ✨ Features

*   **High Contrast:** Pure blacks, pure whites, and sharp borders.
*   **Minimalist & Brutalist:** Removes unnecessary shadows, gradients, and rounded corners (unless specified) for a raw, structural feel.
*   **Bootstrap 5 Ready:** Drop-in replacement/override for standard Bootstrap 5 projects.
*   **Developer Friendly:** Easy to customize, minimal CSS weight.

## 🚀 Installation

1. Include Bootstrap 5 in your project.
2. Link the `zyntaxUI.css` file *after* your Bootstrap CSS to override the default styles:

```html
<!-- Bootstrap 5 CSS -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- zyntaxUI Theme CSS -->
<link href="https://zyntaxui.pages.dev/zyntaxUI.css" rel="stylesheet">
```
